# 论文结构与论证检查

只检查用户指定的全文、章节或段落。先诊断，只有用户要求时才重写；不启动完整科研流程。

## 执行

1. 根据现有材料确认中心问题和主要回答；信息不足时给出暂定理解，标明缺口。
2. 只有在跨段顺序、重复或段落功能是问题时才做反向提纲：用一句话概括相关段落的功能和论点，定位重复、过长背景、缺少过渡、无关段落。单段先指出具体哪两句之间缺了哪一步推理；若未发现影响论证的问题，一句说明即可。保留必要的方法细节，不为了紧凑一律删减。
3. 检查研究缺口是否交代已知、未解决问题、重要性、本文如何回应。仅凭当前综述缺少引用，不能断言整个领域无人研究。
4. 区分新颖性、理论贡献、方法贡献、实证贡献和实践意义；只保留材料支持的类型，不要求每篇论文兼具全部贡献。
5. 按需建立“研究问题—数据/变量—方法—结果—结论”对应表，指出没有回答的问题、没有方法依据的结果及超出研究范围的结论。
6. 如需文献综述诊断，检查其是否按问题、发现、分歧组织，而非逐篇摘要。不得为解释分歧编造原因。

## 输出

先列影响最大的几个问题，每项给出位置、依据和最小修改建议。短文本直接列问题；长章节再附段落提纲或对应表。无问题的段落无需强改。

## 调用例

“检查这段引言的逻辑，先别重写。”
“把研究问题、方法和结论对齐，找出没回答的问题。”
